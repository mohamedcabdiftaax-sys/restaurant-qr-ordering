# Restaurant QR Ordering

Complete starter app for a restaurant QR ordering workflow.

## Included

- Customer digital menu
- Category filtering
- Cart and checkout
- Table-aware orders
- Order status workflow
- Admin dashboard
- Menu management
- Table QR generation + PNG download
- Responsive mobile UI
- LocalStorage persistence (no backend required for the demo)

## Run

```bash
npm install
npm run dev
```

Customer menu: `/`
Admin dashboard: `/admin`

The production version should replace LocalStorage with an API/database and add authenticated admin access.
